# CareBridge Agent Instructions

This file is the repository-first memory for every coding session. Read it before acting.

## Rules

- **Repository-first memory.** Treat this repository's files and documentation as the source of truth. Read the relevant documents before making decisions; do not rely on conversation memory alone.
- **Inspect before edit.** Read the files and directories you intend to change, and check for existing work, before modifying anything.
- **One task at a time.** Work on a single agreed task, finish it, and record the evidence before starting another.
- **Use installed Superpowers skills.** Follow the installed skill-routing instructions and load the relevant skills before starting work.
- **Context manifest.** Before implementation, state which files and documents you will read and which you will create or change, and why.
- **Test first.** Write and run a failing test before writing the implementation that makes it pass.
- **Independent review.** Send completed work to an independent reviewer and resolve blocking findings before calling it done.
- **Evidence before completion.** Run the relevant verification commands and record their real output; do not claim success without evidence.
- **No real patient data or committed secrets.** Use synthetic data only. Never commit credentials, tokens, connection strings, API keys, passwords, or other secret-like values.

See `orchestration/CAREBRIDGE_MASTER_PROMPT.md` for the master prompt and workflow.
